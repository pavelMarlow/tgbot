# ParoHod 2.5 — каталог, навигация и админ-панель

Версия основана на последнем проекте ParoHod 2.4, сохраняет действующий Worker `parohod-miniapp`, базу `parohod-db`, Telegram initData HMAC и администраторов 8204734421 / 5094075415.

## Что нового

- Отдельные SVG-иконки для «Жидкости», «Устройства», «Картриджи» в едином холодно-синем стиле; оформление плиток с анимацией нажатия.
- Дополнительная мягкая анимация главного баннера, поддержка `prefers-reduced-motion`.
- В избранном: добровольный **запрос информации о наличии**, который передаёт выбранные названия и Telegram ID двум администраторам с помощью существующего бота. **Это не заказ, бронирование или оплата.** Перед отправкой показывается подтверждение. Лимиты: не более 15 позиций, минимум минута между запросами, не более 5 за 24 часа на пользователя.
- Админка: массовое изменение статуса наличия только после подтверждения, статистика авторизованных пользователей и запросов.
- 21 существующая позиция, цены, фотографии, поиск, избранное, CRUD и CSV сохраняются.

## Где находятся фотографии, добавленные через админку

Они **не хранятся в ZIP**: они находятся в рабочей Cloudflare D1, в отдельной таблице `product_photos`. Обновление кода и файл `upgrade_2_5.sql` эту таблицу не затрагивают. В обработчике API ручное фото имеет приоритет над автоматическими изображениями. Не удаляйте и не пересоздавайте D1; делайте экспорт перед обновлением. Ранее опубликованные файлы `/public/media/` также входят в архив.

## Установка на Windows (обычный CMD)

Распакуйте ZIP; откройте именно вложенную папку `parohod-miniapp` и в адресной строке Проводника введите `cmd`. Выполните команды из `UPDATE_CMD_2_5.txt`. Сначала проверьте, что `wrangler whoami` указывает на **отдельный аккаунт ParoHod**, а не X VPN. Блок останавливается, если экспорт D1, миграция или проверка сборки завершаются ошибкой. На запрос подтверждения удалённой D1 отвечайте `yes`.

**Не выполняйте `schema.sql`, `catalog_21.sql` или `photo_migration.sql` повторно.** Для 2.5 нужен только `upgrade_2_5.sql`; он добавляет две новые таблицы и индексы, не меняя товары и фотографии. Токен `BOT_TOKEN` уже сохранён как секрет Worker и не входит в архив.

Для получения уведомлений оба администратора должны предварительно нажать Start в чате со своим Telegram-ботом. Если бот не может отправить ни одному администратору, приложение честно сообщает об ошибке. Успешно доставленные запросы учитываются в статистике.

## Ограничения статистики

В статистике учитываются только открывшие приложение **в Telegram с валидным initData после перехода на 2.5**. Дообновлённая история отсутствует. Храним числовой Telegram ID, дату первого и последнего посещения и число визитов; IP-адреса не собираются. Счётчик запроса наличия хранит дату, ID отправителя, количество выбранных позиций и число доставленных сообщений — без содержимого самого списка.

Локальные UI-тесты используют имитацию ответов API и проверяют Chrome/Chromium, а не настоящую пользовательскую сессию Telegram. Живую доставку Telegram-уведомлений и работу D1 после выкладки нужно проверить в двух администраторских чатах.
