# ParoHod 2.3 — фото и проверка источников

Это реальное обновление 2.2, НЕ обещание о том, что все 21 фото уже подтверждены.

- 5 проверенных фотографий/изображений конкретных товарных линеек или моделей локально упакованы в `public/media/`. Фотографии упаковок и устройств не генерировались нейросетью.
- 12 дополнительных позиций подключены через жёстко указанные страницы моделей производителя или продавца: Worker получает реальное изображение/вариант по HTTPS, только когда пользователь открывает карточку. Интернет-доступ сайта необходим; при недоступности источника появляется честная заглушка.
- 4 позиции без подтверждённого фото: `Солевая монашка`, `ISTERIKA X Самоубийца`, `ICE FOX extra hard`, `Картридж Pasito K-5`. Не используются выдуманные или чужие упаковки.
- Для жидкостей без указания вкуса на изображении подписано «Фото линейки; конкретный вкус не указан». Для устройств без указанного цвета — «цвет может отличаться».
- Администратор может заменить любой источник собственным фото; загруженная фотография имеет приоритет.

Важно: это информационный каталог, без онлайн-оплаты или дистанционной продажи. Разрешение на повторную публикацию фотографий сторонних сайтов/производителей не проверялось; перед коммерческим размещением согласуйте права с поставщиком или замените их собственными снимками.

Полный реестр по каждой позиции: `PHOTO_STATUS.json`.
